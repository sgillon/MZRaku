# MZ-800

MZRaku emulates the Sharp MZ-800 with its MZ-800 display modes, the
SN76489 sound chip, the two joystick ports and Sharp's MZ-800 BASIC
(1Z-016). MZ-700 machine-code titles run in the MZ-800's MZ-700
compatibility mode, as they do on the real machine.

Most of the emulator works the same way it does on the MZ-700. This
page covers what's specific to the MZ-800.

## Getting started

You need two files (see the [Quickstart](../../README.md#quickstart)):

| File | Where it goes | What it is |
|---|---|---|
| `MZ800.ROM` | `roms\` | The MZ-800's 16 KiB combined ROM: MZ-700 monitor, character generator, and the MZ-800 IPL and monitor. |
| `1Z-016.mzf` | `basic\` (or `roms\`) | Sharp's MZ-800 BASIC, supplied on cassette. |

Some other emulators, such as EmuZ-800, use the same ROM as three
separate files. MZRaku needs the single combined file for now. You can
make it from the three parts by running this in the folder that holds
them:

```
copy /b MZ700IPL.ROM+FONT.ROM+MZ800IPL.ROM MZ800.ROM
```

To start the MZ-800:

- for one run, use `MZRaku.exe --mz800`;
- to switch for this session, use **System → Machine → MZ-800**;
- to make it the default, use **System → Settings → Startup → Default
  machine** (stored as `[Machine] DefaultMachine=MZ800`).

The machine boots to the IPL boot menu ("Make ready CMT" / "Please
push key", with C for cassette and M for the monitor). **File → Load
BASIC** (Ctrl+B) or `--basic` loads 1Z-016 and leaves you at its
`Ready` prompt.

## Loading software

**Load cassette** (Ctrl+O), drag-and-drop and a file on the command
line all reset the machine, wait for the IPL boot menu, and then:

- **Machine-code programs** are loaded and started directly. This
  includes MZ-700 machine-code titles.
- **MZ-800 BASIC programs** load BASIC first, then BASIC's own `LOAD`
  and `RUN` are typed for you. The whole tape is inserted, so a
  program that loads further files by name (for example a BASIC
  loader followed by its machine code) finds them.
- **MZ-700 BASIC programs** (S-BASIC) can't run under 1Z-016. The
  status bar tells you to use the MZ-700 instead.

`.zip`, `.mzf`, `.m12` and `.mzt` files all work. A `.zip` or `.mzt`
holding several files is treated as one tape with the files in order.

**File → Insert cassette for LOAD…** inserts a tape without resetting,
for the machine's own loading: the IPL's C option, the monitor's L, or
BASIC's `LOAD` / `LOAD "name"`. As on a real tape, a named `LOAD` skips
files whose names don't match.

**File → Load BASIC source…** (Ctrl+Shift+B) types a plain-text
listing into 1Z-016, as on the other machines. If BASIC isn't running
it's loaded first, and typing starts once BASIC is waiting for a key.

## Keyboard

Typing works the same way as on the MZ-700: the character your PC
produces is sent to the MZ-800 (see [Keyboard](keyboard.md)). The
non-character keys are:

| PC key | MZ-800 |
|---|---|
| Enter | CR |
| Tab | TAB |
| Backspace / Delete | DEL |
| Insert | INST |
| Esc | BREAK (**Shift+Esc** to stop a running BASIC program) |
| Cursor keys | Cursor |
| Ctrl | CTRL |
| F1–F5 | F1–F5 |
| F11 | GRAPH |
| F12 | ALPHA (**Shift+F12** toggles shift lock in BASIC) |

**System → Settings → Keyboard** shows the MZ-800's own keyboard.
It's laid out from the Owner's Manual: the MZ-700 main block, with
TAB on the QWERTY row and ALPHA beside a narrower left SHIFT. Editing
works exactly as on the MZ-700. Your changes are saved to
`[CharMap.MZ800]` and `[KeyOverrides.MZ800]` in `settings.ini`.
Exported `.mzkbd` files are marked as MZ-800 files, and importing a
file made for another machine is refused.

Pressing GRAPH opens the **Font Sheet** so you can see the graphic
characters. On the MZ-800 the Font Sheet is view-only for now: clicking
a character doesn't type it.

## Status bar

The MZ-800 has two status-bar panes on the right:

- **Display mode** shows `MZ-700`, `320×200` or `640×200`. Hover over
  it for details.
- **Keyboard mode** shows `ALPHA`, `LOCK` (shift lock) or `GRAPH`.
  This is read from 1Z-016 itself, so it always matches what BASIC
  will do with the next key. When BASIC isn't running (at the IPL
  menu, in the monitor or in a game) the pane shows `—`.

## Display

All MZ-800 display modes are emulated:

- 320×200 in 4 or 16 colours;
- 640×200 in 2 or 4 colours;
- MZ-700-mode text.

The palette, hardware scrolling and split-screen scrolling are also
emulated.

Some modes need the **MZ-1R25** 16 KB VRAM expansion. It's fitted by
default; you can remove it under **System → Settings → Display →
MZ-800** (`[Hardware.MZ800] MZ1R25=`). The change applies straight
away. Titles that use 16 colours, such as Uridium, need it fitted.

Scanlines, full-screen and window scaling work as on the other
machines.

## Sound

The MZ-800's SN76489 sound chip and its 8253 beeper are both emulated
and mixed together. BASIC's `MUSIC` and in-game music play through
it. **Debug → Sound Diagnostic…** shows the chip's
three tone channels and noise channel live, alongside the beeper.

## Joystick

The MZ-800 has two Atari-style digital joystick ports (the MZ-1X16).
Your PC gamepads drive them: the first controller is joystick 1 and
the second is joystick 2. A direction counts once the stick is a
quarter of the way from centre; the D-pad works too. The two trigger
buttons use the same `Button1` / `Button2` mapping as the MZ-700 (see
[Joystick](joystick.md) and **System → Settings → Joystick**).

## Debug tools

The Debugger, Memory Viewer, HID Diagnostic, Sound Diagnostic and
Keyboard Matrix windows all work on the MZ-800. The Memory Viewer's
bank line shows the current memory banking and display mode.

## Known limitations

- **BASIC `SAVE` doesn't work yet.** It waits for a tape that never
  starts. Planned for v1.4.0.
- **No floppy disk, Quick Disk or printer.** `LPRINT` and `LLIST` wait
  forever for a printer.
- **The Font Sheet is view-only.** Click-to-type for the MZ-800 is
  planned for v1.4.0.
- **The border isn't drawn.** Programs that change the border colour
  show no change.
