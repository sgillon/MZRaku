# MZ-700

The Sharp MZ-700 is MZRaku's first machine and its default. MZRaku
emulates it with its colour text display, the beeper, the MZ-1X03
joystick and Sharp's S-BASIC (1Z-013B).

## Getting started

You need three files (see the [Quickstart](../../README.md#quickstart)):

| File | Where it goes | What it is |
|---|---|---|
| `1z-013a.rom` | `roms\` | The MZ-700 monitor ROM (4 KiB). |
| `mz700fon.int` | `roms\` | The character generator ROM (the font). |
| `1Z-013B.mzf` | `basic\` (or `roms\`) | Sharp's S-BASIC, supplied on cassette. |

The MZ-700 starts when nothing else is chosen. Otherwise:

- for one run, use `MZRaku.exe --mz700`;
- to switch for this session, use **System → Machine → MZ-700**;
- to make it the default again, use **System → Settings → Startup →
  Default machine** (stored as `[Machine] DefaultMachine=MZ700`).

The machine boots to the monitor's `*` prompt. **File → Load BASIC**
(Ctrl+B) or `--basic` loads S-BASIC and leaves you at its `Ready`
prompt.

## Loading software

**Load cassette** (Ctrl+O), drag and drop, and a file on the command
line all load a program and run it for you:

- **Machine-code programs** are loaded and started straight away.
- **BASIC programs** reset the machine, load S-BASIC, put the program
  in memory and type `RUN`.

`.zip`, `.mzf`, `.m12` and `.mzt` files all work; from a `.zip` or
`.mzt`, the first file is used.

**File → Insert cassette for LOAD…** (or `--insert=<file>` on the
command line) puts a tape in the cassette deck without resetting, for
the machine's own loading: the monitor's `L`, or S-BASIC's `LOAD`.

**BASIC `SAVE`** writes the program as an `.mzf` in a `saves\` folder
next to `MZRaku.exe`, named after the program (`SAVE "GAME"` writes
`GAME.mzf`; an existing file isn't overwritten: `GAME-1.mzf` is
written instead). BASIC returns to `Ready` as usual.

**File → Load BASIC source…** (Ctrl+Shift+B) types a plain-text
listing into S-BASIC. If BASIC isn't running it's loaded first. See
[Loading BASIC source](keyboard.md#loading-basic-source).

## Keyboard

The character your PC produces is sent to the MZ-700, whatever your
keyboard layout (see [Keyboard](keyboard.md)). The non-character keys
are:

| PC key | MZ-700 |
|---|---|
| Enter | CR |
| Backspace / Delete | DEL |
| Insert | INST (**Shift+Insert** is CLR) |
| Esc | BREAK (**Shift+Esc** to stop a running BASIC program) |
| Cursor keys | Cursor |
| Ctrl | CTRL |
| F1–F5 | F1–F5 |
| F11 | GRAPH |
| F12 | ALPHA (**Shift+F12** turns shift lock on in BASIC) |

S-BASIC's function keys type `RUN`, `LIST`, `AUTO`, `RENUM` and
`COLOR` on F1–F5, and `CHR$(`, `DEF KEY(`, `CONT`, `SAVE` and `LOAD`
with Shift.

Pressing GRAPH in S-BASIC opens the **Font Sheet**, where you can click a
graphic character to type it (see
[Font Sheet](keyboard.md#font-sheet)). The keyboard can only type
some of the MZ-700's characters; for the rest the Font Sheet shows the
BASIC that puts them on screen.

**System → Settings → Keyboard** shows the MZ-700's keyboard. Click a
key to change which PC key types it. Your changes are saved to
`[CharMap]` and `[KeyOverrides.MZ700]` in `settings.ini`.

## Status bar

From the left: the machine name, messages, then panes that appear
when they apply (speed, `MUTED`), the **TAPE** light (pale yellow
while a cassette is inserted and waiting, orange as it's read or
written), and the **keyboard mode**: `ALPHA`,
`LOCK` (shift lock) or `GRAPH`. The mode is read from S-BASIC itself,
so it always matches what BASIC will do with the next key. When
S-BASIC isn't running (in the monitor or a game) the pane shows `—`.

## Display

40 × 25 characters in eight colours, from the character ROM's two
banks of 256 characters. **View** sets the window to 1×, 2× or 3×
(Ctrl+1 to Ctrl+3), full screen (Alt+Enter) and scanlines (Ctrl+L);
**System → Settings → Display** keeps them. **View → Save screenshot**
(Ctrl+P) saves the screen as a PNG in a `screenshots\` folder next to
`MZRaku.exe`, at the MZ-700's own 320 × 200.

## Sound

The MZ-700's beeper: the 8253 timer's square wave through its two
speaker gates. BASIC's `MUSIC` and the boot tone play through it.
**System → Sound** has the volume and **Mute** (Ctrl+U); both are
remembered. **Debug → Sound Diagnostic…** shows the timer and the
speaker gates live.

## Joystick

MZRaku emulates the **MZ-1X03** dual joystick interface, driven by
your PC gamepads: the first controller is stick 1, the second stick 2.
See [Joystick](joystick.md).

## Debug tools

The [Debugger](debugger.md), [Memory Viewer](memory-viewer.md),
[HID Diagnostic](hid-diagnostic.md), Sound Diagnostic and Keyboard
Matrix windows all work on the MZ-700.

## Known limitations

- **The monitor's own tape save isn't supported.** Use BASIC's `SAVE`.
- **No printer or plotter.** The MZ-1P01 plotter isn't emulated.
- **`MUSIC` timing** comes from the CPU clock rather than an emulated
  oscillator: right by ear, not measured to the millisecond.
- **Typed BASIC source is slow**, a few characters a second, because
  each key waits for the ROM to see it.
